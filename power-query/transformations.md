# Power Query Transformations

Power Query is the transformation layer between Snowflake and the Power BI semantic model.

## M Code

The supplied PBIX package does not expose its embedded Power Query DataMashup/M code as readable text. No M code has been fabricated for this repository. If the M code is exported from Power Query's Advanced Editor, it can be added here as `M_Code.txt`.
